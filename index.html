How It Works

1cron-job.org triggers the GitHub workflow.
2GitHub Actions runs status.js.
3The alt Microsoft account checks StoneHaven online players.
4XUIDs are converted into Xbox gamertags.
5The permanent Discord message is edited in #online.
6The dashboard status.json file is updated.

Reset Permanent Discord Message

Use this when the bot avatar/icon does not update

1Disable cron-job.org for a minute.
2Set STATUS_MESSAGE_ID to none.
3Run the GitHub workflow manually.
4Copy the new message ID from the workflow logs.
5Save the new ID back into STATUS_MESSAGE_ID.
6Delete the old Discord status message.
7Turn cron-job.org back on.
The code treats none and NONE as blank, so it creates a new permanent message.

Troubleshooting

Workflow says Cannot find package prismarine-auth

status.yml is missing the npm install step.

Microsoft login asks every run

The auth cache step is missing or did not save. Check actions/cache@v4 with path: auth-cache.

Thumbnail shows the wrong image

Add a cache buster to the image URL, like ?v=2.

Bot avatar does not update

Set STATUS_MESSAGE_ID to none, run workflow, save the new ID.

Cron is not running

Check cron-job.org is enabled and the test run returns 204 No Content.

Dashboard is not updating

Check that status.json exists and GitHub Pages has refreshed. Try opening the site with ?v=10 at the end.
